# Instruções do projeto

- O portfólio apresenta Fabbio Boli como desenvolvedor Full Stack. Use apenas informações e realizações verificadas ou fornecidas pelo proprietário.
- O catálogo vem de `content/github-projects.json`, atualizado por `npm run sync:github` e pelo workflow agendado. Preserve o destaque principal de Codex Automation Recommender, as regras `portfolio-featured` e `portfolio-ignore` e a exclusão do repositório do portfólio.
- Projetos editoriais sem repositório público não devem receber links inventados. Preserve os links e contatos existentes.
- O PDF público do currículo deve permanecer sem endereço e data de nascimento. Não copie versões antigas para os arquivos publicados nem envie histórico Git antigo sem revisão de dados pessoais.
- Mantenha a navegação acessível por teclado, modo claro/escuro, layout responsivo e suporte a movimento reduzido.
